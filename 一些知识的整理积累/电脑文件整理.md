# Windows 文件整理工具与使用指南（新手友好）

适用于 Windows 系统，免费、无广告、易上手，包含：文件搜索、管理、自动分类、重复清理。

---

## 软件套装（4 件套）

### 1. Everything（极速搜索）
- 功能：秒搜全盘文件
- 官网：https://www.voidtools.com/zh-cn/
- 下载：https://www.voidtools.com/downloads/Everything-1.4.1.1030.x64-Setup.exe

### 2. OneCommander（文件管理器）
- 功能：双窗格、多标签、预览、批量重命名
- 官网：https://onecommander.com/
- 微软商店：https://www.microsoft.com/zh-cn/p/onecommander/9nblggh4s79b

### 3. DropIt（自动分类）
- 功能：拖拽自动归类文件
- 官网：https://www.dropitproject.com/
- 微软商店：https://www.microsoft.com/zh-cn/p/dropit/9wzdncrdn6ln

### 4. Czkawka（重复文件清理）
- 功能：重复文件、大文件、空文件夹、相似图片扫描
- 下载：https://github.com/qarmin/czkawka/releases/latest/download/windows_czkawka_gui.zip

## 快速设置步骤

### Everything 设置
1. 安装时勾选：随系统启动、安装服务
2. 工具 → 选项
   - 随系统启动
   - 最小化到托盘
   - 集成右键菜单
3. 快捷键：建议设置为 `Win+S`
4. 使用：输入关键词即可搜索

### OneCommander 设置
1. 设置 → 语言 → 简体中文
2. 视图 → 开启双窗格、预览面板
3. 常用操作
   - 空格：预览文件
   - 多选文件 → 右键 → 批量重命名

### DropIt 自动分类规则
1. 右键悬浮窗 → 语言 → 简体中文
2. 新建配置文件：文件分类
3. 新建协议规则：

**图片**
- 匹配：`*.jpg;*.png;*.gif;*.bmp;*.webp`
- 动作：移动
- 目标：`D:\图片`

**文档**
- 匹配：`*.doc;*.docx;*.pdf;*.txt;*.xls;*.xlsx`
- 动作：移动
- 目标：`D:\文档`

**压缩包**
- 匹配：`*.zip;*.rar;*.7z;*.tar`
- 动作：移动
- 目标：`D:\下载归档`

4. 使用：将杂乱文件夹拖到悬浮窗自动分类

### Czkawka 使用
1. 解压后运行 `czkawka_gui.exe`
2. 左侧选择：重复文件
3. 添加扫描目录 → 开始扫描
4. 勾选文件 → 删除到回收站

---

## 日常使用流程
1. 找文件：`Win+S` 打开 Everything
2. 管理文件：OneCommander 双窗格拖放
3. 自动整理：拖到 DropIt 分类
4. 空间清理：每月用 Czkawka 扫描重复文件

---

## 注意事项
- 仅从官网/微软商店下载
- 安装时取消捆绑软件
- 文件命名建议：`日期-内容` 格式
- 重要文件先放入回收站，确认无误再清理
